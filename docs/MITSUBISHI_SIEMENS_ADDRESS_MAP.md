# Mitsubishi ↔ Siemens 주소 매핑 테이블

이 문서는 Mitsubishi(GX Works) PLC 디바이스 주소를 Siemens(TIA Portal) PLC 주소로 변환할 때의 매핑 규칙을 정리한 것입니다.

> 이 매핑은 `convert_comment_to_tagtable.py`에서 실제 사용 중인 변환 규칙 기준입니다.

## 비트(Bool) 디바이스

| Mitsubishi | 설명 | Siemens | 설명 | 주소 변환 규칙 |
|------------|------|---------|------|----------------|
| **X** | 입력 접점 (16진수) | **%I** | Input | `X{hex}` → `%I{hex/16}.{hex%16}` (bit≤7일 때) |
| **Y** | 출력 접점 (16진수) | **%Q** | Output | `Y{hex}` → `%Q{hex/16}.{hex%16}` (bit≤7일 때) |
| **M** | 보조 릴레이 | **%M** | Merker (비트) | `M{n}` → `%M{n/8}.{n%8}` |
| **SM** | 특수 릴레이 | **%M** | Merker (상위 영역) | `SM{n}` → `%M{10000+n/8}.{n%8}` |
| **L** | 래치 릴레이 | **%M** | Merker (래치 영역) | `L{n}` → `%M{5000+n/8}.{n%8}` |

## 워드(16비트) 디바이스

| Mitsubishi | 설명 | Siemens | 설명 | 주소 변환 규칙 |
|------------|------|---------|------|----------------|
| **D** | 데이터 레지스터 (16-bit) | **%MW** | Merker Word | `D{n}` → `%MW{n*2}` |
| **SD** | 특수 레지스터 | **%MW** | Merker Word (상위 영역) | `SD{n}` → `%MW{20000+n*2}` |
| **T** | 타이머 (현재값) | **%MW** | Merker Word (타이머 영역) | `T{n}` → `%MW{30000+n*2}` |
| **ZR** | 파일 레지스터 | **%MW** | Merker Word (파일 영역) | `ZR{n}` → `%MW{40000+n*2}` |

## 더블워드(32비트) 디바이스

| Mitsubishi | 설명 | Siemens | 설명 | 주소 변환 규칙 |
|------------|------|---------|------|----------------|
| **R** | 실수 레지스터 (32-bit) | **%MD** | Merker DWord | `R{n}` → `%MD{n*4}` |

## 상수(Constant)

| Mitsubishi | 설명 | Siemens | 비고 |
|------------|------|---------|------|
| **K** | 10진 상수 | 정수 리터럴 | `K100` → `100` |
| **H** | 16진 상수 | `16#` 접두어 | `HFF` → `16#FF` |

## 미지원 디바이스

| Mitsubishi | 설명 | 비고 |
|------------|------|------|
| **U\G** | 버퍼 메모리 | 모듈 종속적이라 자동 변환 제외 |
| **C** | 카운터 | 현재 미구현 |
| **B** | 링크 릴레이 | 현재 미구현 |
| **W** | 링크 레지스터 | 현재 미구현 |
| **F** | 어나운서 | 현재 미구현 |

## Siemens 주소 체계 요약

| 접두어 | 의미 | 데이터 크기 | 예시 |
|--------|------|-------------|------|
| `%I` | Input (입력) | Bit | `%I0.0` |
| `%IB` | Input Byte | 8-bit | `%IB0` |
| `%IW` | Input Word | 16-bit | `%IW0` |
| `%Q` | Output (출력) | Bit | `%Q0.0` |
| `%QB` | Output Byte | 8-bit | `%QB0` |
| `%QW` | Output Word | 16-bit | `%QW0` |
| `%M` | Merker (내부 메모리) | Bit | `%M0.0` |
| `%MB` | Merker Byte | 8-bit | `%MB0` |
| `%MW` | Merker Word | 16-bit | `%MW0` |
| `%MD` | Merker DWord | 32-bit | `%MD0` |
| `%DB` | Data Block | 가변 | `%DB1.DBX0.0` |

## 주소 영역 배치도 (Merker 기준)

```
%M 영역 할당:
├── %M0.0 ~ %M4999.7      ← M (보조 릴레이)        M0~M39999
├── %M5000.0 ~ %M9999.7   ← L (래치 릴레이)        L0~L39999
├── %M10000.0 ~            ← SM (특수 릴레이)       SM0~

%MW 영역 할당:
├── %MW0 ~ %MW19999        ← D (데이터 레지스터)    D0~D9999
├── %MW20000 ~ %MW29999    ← SD (특수 레지스터)     SD0~SD4999
├── %MW30000 ~ %MW39999    ← T (타이머)             T0~T4999
├── %MW40000 ~             ← ZR (파일 레지스터)     ZR0~

%MD 영역 할당:
├── %MD0 ~                 ← R (실수 레지스터)      R0~
```

## 주의사항

- Mitsubishi X/Y는 **16진수(Hex)** 주소 체계 (Q/iQ-R 시리즈 기준, FX 시리즈는 8진수), Siemens %I/%Q는 **10진수** 바이트.비트 체계
- D 레지스터는 16-bit이므로 Siemens %MW 매핑 시 `n*2` 오프셋 (바이트 주소 기준)
- 32-bit 연산(DMOV 등)은 D 두 개를 연속 사용하므로 %MD로 매핑 필요
- 영역 간 충돌 방지를 위해 오프셋 구간을 분리 배치함
